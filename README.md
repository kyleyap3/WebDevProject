

# Taste of Kyle — WebDevProject

Welcome to the **Taste of Kyle** website — a personal recipe and profile site built with **HTML** and **CSS**, and hosted live on GitHub Pages! ([GitHub Docs][1])

This repository contains all the source files for the site, including pages like **Home**, **About Me**, and individual recipe pages.

---

## 🌐 Live Site

Check out the published website here:

👉 [https://kyleyap3.github.io/WebDevProject/](https://kyleyap3.github.io/WebDevProject/)

---

## 📂 Project Contents

The main folders and files in this repo include:

* `index.html` — The homepage of the site
* `about.html` — About Me page
* Other recipe HTML pages
* `style.css` — Main stylesheet
* `images/` — Recipe and profile images
* `fonts/` — Custom fonts used on the site

---

## 🧩 What It Does

This is a **static website** created using only front‑end technologies:

✔️ HTML for page structure
✔️ CSS for styling
✔️ Hosted with **GitHub Pages** for free static hosting ([GitHub Docs][2])

It showcases various Filipino recipes with images and step‑by‑step instructions, as well as an About Me section.

---

## 🚀 How to Use

If you want to work with the site locally:

1. Clone this repository:

```bash
git clone https://github.com/kyleyap3/WebDevProject.git
```

2. Open the `.html` files in your browser to view pages locally.
